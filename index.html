🔥 Configuration Firebase

Étapes rapides (tu as déjà Firebase, c'est facile) :
1. Va sur console.firebase.google.com
2. Ouvre ton projet → ⚙ Paramètres → Général
3. Défile jusqu'à Tes applications → clique </> Web (si pas encore créé, ajoute une app web)
4. Copie le bloc firebaseConfig et colle les valeurs ci-dessous
5. Active Firestore Database dans ton projet (mode test OK pour commencer)
